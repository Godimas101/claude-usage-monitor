NOSTROMO / INSTRUMENT / SHEET 01

Nostromo Usage Monitor

Floating widget, taskbar strip, tray icon and dashboard overview on one sheet. The widgets use only rectangles, polygons, lines, text, one blur glow and simple gradients, so Pillow can draw them at the same pixel positions. The switch re-tints sections 01 to 04. Section 05 always shows all five phosphors.

01Floating widget280 x 124 px at 100 percent. Session, weekly and fable share rows.

1x, actual sizeNormal state with three rows. The hairline above each pip bar is the window's elapsed time. Lit pips are usage. Where the lit pips run past the hairline, usage is ahead of pace.

3x zoom copyThe same widget at three times size, using CSS zoom. Scanlines and glow scale with it, so judge the fine detail at 1x.
