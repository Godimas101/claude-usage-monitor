Decisions for the owner

  1. Pick one weekly reset. The brief's Wed 4:00 PM had already passed by the 4:12 PM sample clock, so each mock chose a different day: Sat 4:00 PM (nostromo), Mon 9:00 AM (night city) and Sun 4:00 PM (gates). The session reset is 7:39 PM in each normal state.
  2. Check the names. The ids nostromo and night_city, and the display name Night City, borrow film and game titles. The brief allowed homage through style, colour, type and copy only, so confirm these or rename them before the theme files are used.
  3. Choose the reference theme for the Pillow widgets. The other two specs stay in usage_monitor/themes/ as alternates.
  4. Verify on hardware before shipping: a real 100% taskbar, the notification area at 100, 125 and 150% DPI, and the WebView2 font names for gates. The 70% and 90% severity thresholds are placeholders in the nostromo spec.

Nostromo

The shipped amber-on-CRT identity, sharpened.

Open live mock Theme spec (JSON)

Nostromo keeps the amber-on-CRT look the app already ships and makes it exact. Widgets are flat and chamfered, with 16-cell pip bars and a time rail under each bar, so pace reads straight off the widget. Status is carried by shape and word (a boxed pill, a severity word and a static inverted chip for critical), never by blinking or colour alone.

Fonts and licences

  • Michroma: display, SIL OFL 1.1
  • IBM Plex Mono SemiBold 600 and Regular 400: labels, SIL OFL 1.1
  • VT323: readouts, percentages and the tray centre, SIL OFL 1.1
  • Segoe UI Variable Text: taskbar clock only, Windows system font, not bundled

Open items

  • Not checked on a real 100% taskbar. The light-taskbar row is a mock only.
  • Baselines marked “verify” come from CSS measurement and need a check against the Pillow render.
  • Weekly reset is Sat 4:00 PM, so 57% of the 7-day window is gone. Severity thresholds at 70% and 90% are placeholders.
  • Settings, History and About are nav entries only. No pages are designed.

Night City

A chamfered in-game HUD in salmon, cyan and signal yellow.

Open live mock Theme spec (JSON)

Every frame is a chamfered polygon with a hairline edge and corner brackets, so the widget reads as an in-game HUD. Salmon carries usage, cyan carries LIVE and the pace line, and signal yellow is kept for WARN, CRIT, STALE and stamps. Hazard stripes appear only on the critical fill, the stale band and the CRIT cap. The LIVE pip breathes on a 2.4 s pulse instead of blinking, and numerals refresh with a short RGB split once per data refresh.

Fonts and licences

  • Chakra Petch Bold and SemiBold: numerals and headings, SIL OFL 1.1
  • Rajdhani Bold and SemiBold: labels, chips and nav, SIL OFL 1.1
  • Share Tech Mono: values, reset times and data text, SIL OFL 1.1
  • Segoe UI Variable: taskbar mock only, Windows system font, not bundled

Open items

  • No real notification-area test at 100, 125 or 150% DPI. The tray octagon is a generic placeholder shape.
  • The refresh hit plays once on load in the mock so it is visible. The app should add it only on real refreshes.
  • In edgerun, WARN moves to red-orange (#ff7a1a) so the yellow stays the signature colour.
  • Weekly reset is Mon 9:00 AM, so 33% of the 7-day window is gone.

Gates

A Windows Quick Settings card in the accent you pick.

Open live mock Theme spec (JSON)

Each limit row is a 288 × 128 Quick Settings card. A thin time rail, showing the share of the window already gone with an index tick at its end, sits above the usage bar, so pace is the gap between the two. Status is a tinted pill with its age, such as LIVE · 12 s. Severity colours only the bar and the value. The dashboard follows the Settings shell, with search, profile, an icon nav with a 3 px accent indicator, and pace lanes.

Fonts and licences

  • Segoe UI Variable Display and Text: Windows 11 system font, Microsoft terms, read from C:\Windows\Fonts, not bundled
  • Segoe Fluent Icons: Windows 11 system font, same terms, not bundled
  • Cascadia Mono (variable 200–700): SIL OFL 1.1, bundled
  • Consolas and system-ui: mock-only fallbacks

Open items

  • The dashed stale ring reads as dotted at 16 px and can resemble a loading ring at 24 and 32 px. Solid grey is the fallback if users confuse it.
  • Not verified: whether WebView2 resolves the Segoe UI Variable Display and Text family names, or needs Segoe UI Variable. The named-instance mapping is in gates.json.
  • System accent and Blue are both blue by design. The mock uses the Windows default; the app reads the live accent.
  • Light and dark are separate variants. System mode picks the dark or light entry of the chosen accent.
